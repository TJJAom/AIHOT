# 使用規則

| 項目 | 說明 |
|---|---|
| 網站 | 日耕 AI 熱點 |
| 營運主體 | 日耕工作室 |
| 版本 | 1.3 |
| 生效日期 | 2026-11-03 |
| 聯絡方式 | 意見回饋 /feedback |

頁首說明：

> 日耕 AI 熱點整理公開 AI 資訊，使用 AI 模型產生台灣繁體中文摘要、文章整理與精選。網站供公開閱讀，不需註冊；後台僅供管理者使用。

## 1. 內容與來源

本站提供摘要、AI 文章整理、推薦理由與原文連結。AI 文章整理依來源材料撰寫重點、背景與細節，並非原作者全文或逐字翻譯，不取代來源全文。原文、圖片與品牌的權利歸各權利人所有。
本站持續檢查既有 18 個公開信源，使用 OpenAI GPT-6 Luna 整理符合公開資格的文章；日報預定於每日台灣時間 22:00 產生，資料處理未完成時延後重試。來源拒絕存取、服務故障或停機可能造成延遲或缺漏，不以生成內容補造缺少的原文。
模型生成內容可能遺漏脈絡或判斷錯誤；重要資訊請開啟原文核對發布時間、數字與適用條件。

## 2. 更正與下架

來源方或讀者如發現錯誤、權利疑慮，或希望調整展示方式，可透過[意見回饋](/feedback)提供文章網址與具體說明。
本站依收到的資料確認處理方式，不預先承諾固定處理期限。

## 3. 閱讀與資料使用

網頁、RSS、公開 API 與 MCP 可供匿名閱讀及查詢。使用摘要時請保留來源與原文連結，勿將模型整理冒稱為原作者全文或正式聲明。
公開閱讀不代表本站能代第三方授予著作、圖片或商標的轉載與商業使用權；其他利用方式請先確認相關權利。

## 4. 接口與使用頻率

RSS、公開 API 與 MCP 為唯讀入口。請依回應中的快取期限查詢；收到 429 時遵守 Retry-After，不以大量並行請求或重試影響服務。
請勿嘗試進入管理後台、規避存取限制或提交惡意內容。

## 5. 服務說明

本站依目前可用狀態提供內容，可能因來源變動、模型處理或維護而更新、延遲或暫停。
網站透過 Cloudflare CDN 與 Tunnel 提供公開連線。模型與個人資料處理方式見[隱私說明](/privacy)。
