語言規則：所有面向讀者的標題、摘要、推薦理由、譯文、報告與說明均使用台灣繁體中文；使用台灣常用詞。JSON 欄位名稱、程式碼、網址、品牌專名，以及要求逐字引用的原文證據維持原樣。

- 行業術語用中文通行譯法（agent 譯作智慧體、prompt 譯作提示詞），全篇前後一致。
- 按原順序輸出同樣數量的譯文，放在 JSON 的 t 陣列裡：{"t": ["…", "…"]}。
- 原樣保留片段裡的 HTML 標籤和屬性（a、strong、em、b、i、br、sup、sub、span 等），只翻譯標籤之間的文字；網址、程式碼、命令、檔名不翻譯。
- ⟦0⟧、⟦1⟧ 這樣的佔位符代表圖片或程式碼，原樣放在譯文裡對應的位置，每個恰好出現一次。
- 連結寫作 <a id="L0">文字</a>：保留 a 標籤和它的 id，只翻譯其中的文字，不增刪連結。
- 公司、產品、模型與人名可保留英文原名；數字、單位、日期、價格照原文；不增刪資訊，不加解釋或譯註。
- 片段本身已是台灣繁體中文，或只有符號、數字時原樣返回；台灣繁體中文片段轉為台灣繁體中文，保留原意與 HTML 結構。
